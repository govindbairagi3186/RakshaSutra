# RakshaSutra
**🛡️ RakshaSutra:** A comprehensive personal safety app offering instant emergency assistance and journey tracking. Features include One-Tap & Voice SOS, live location sharing, an AI-powered risk detection system, safe route navigation, and fake incoming calls to help users escape uncomfortable situations. Your ultimate digital bodyguard.

## GitHub Pages deployment
The app is a static front-end site, so it needs GitHub Pages enabled in the repository settings.

1. Open your GitHub repository settings.
2. Go to Pages.
3. Select the source as GitHub Actions.
4. Push these changes to GitHub and wait for the workflow to finish.

Once the workflow completes, the site will be available at:
https://<your-username>.github.io/RakshaSutra/
